Política de Privacidade – Editor de Videos

Última atualização: 21/11/2026

O Editor de Videos é uma ferramenta de uso pessoal e não comercial.

Dados acessados

Com a autorização do usuário, a ferramenta acessa o Google Drive do próprio usuário apenas para: ler os vídeos e o texto de pedido colocados na pasta "Edições de Vídeo / 1 - Pedidos"; enviar o vídeo editado para "2 - Prontos"; e mover o pedido concluído para "3 - Arquivo".

Uso e compartilhamento

Os arquivos são usados exclusivamente para gerar o vídeo editado. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. Cópias temporárias são processadas em um ambiente de execução isolado e descartadas ao fim de cada execução.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
